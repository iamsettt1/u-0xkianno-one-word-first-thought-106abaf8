One word, first thought: a program that writes a single word — the first word that comes to mind — to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty. The word was chosen by measuring candidates head-to-head against the house judge brief (surprise, vividness, wit) on the server judge model.

## Run it

```sh
python3 main.py
```
